# spotapi comes from TzurSoffer's fork, not PyPI, and is PINNED to a commit.
#
# It was previously installed only inside the Dockerfile ("pip uninstall spotAPI
# -y && pip install git+.../SpotAPI", no ref), which meant two things: every
# --no-cache build took whatever was on that branch at the time, and the tests
# ran against PyPI spotapi while the shipped image ran the fork. The two are not
# interchangeable - the fork is 1.3.0 against PyPI's 1.2.8, and they differ in
# spotapi/status.py and spotapi/websocket.py, which are precisely the modules
# Database/patches.py monkey-patches (PlayerStatus.renew_state raises
# WebSocketError on a malformed device dump in the fork, where PyPI's does a bare
# subscript). So the one dependency this codebase patches most heavily was the
# one it never tested against.
#
# Bump the SHA deliberately, with any fallout fixed in the same commit - same
# reasoning as the pinned ruff/eslint versions in the lint workflow.
spotapi @ git+https://github.com/TzurSoffer/SpotAPI@d538654574e2fb9511d1d09012aee962d380df8c
