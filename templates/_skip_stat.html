{# Skip summary for one entity, rendered onto the hero card's `track-meta small` line by the song/artist/album detail pages (see _track_card.html). Deliberately NOT rendered by every caller of that card: it renders on the top lists, Wrapped, Compare and the public share page too, where these numbers aren't loaded - so the card opts in via `showSkipStats` and this is a no-op otherwise. The PLAYS count is deliberately absent. The line this joins already opens with the card's own "N plays", and that is the same figure by a different route (both count non-skip plays), so restating it read as two separate statistics that happened to agree. What's left is the half the line didn't have: how often the entity was skipped, and what share of encounters that is - a rate alone hides how much listening it rests on, which is exactly why the Charts lists shrink theirs toward the library average before ranking on it. `skipStats` is {plays, skips, skipPercent} from Database.getSkipStats; absent or fully empty renders nothing. `leadIn` says whether the line already has content in front of this, i.e. whether to open with a separator - a skip-only entity's card shows no plays figure. #} {% macro skipSummary(skipStats, leadIn=false) -%} {%- if skipStats and (skipStats.plays or skipStats.skips) -%} {%- if leadIn %} · {% endif -%} {%- if skipStats.skips -%} {{ skipStats.skips }} skip{{ 's' if skipStats.skips != 1 else '' }} · {{ skipStats.skipPercent }}% skipped {%- else -%} Never skipped {%- endif -%} {%- endif -%} {%- endmacro %}
